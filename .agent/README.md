# MossMan - Agent Documentation

This directory contains documentation specifically structured for AI agents to understand the project architecture, standards, and workflows.

## Directory Structure

- **`architecture.md`**: High-level system design and architecture.
- **`standards.md`**: Coding standards for Java GUI and backend.
- **`workflows/`**: Step-by-step guides (e.g., adding a new screen).
- **`knowledge/`**: Documented tribal knowledge and technical "gotchas".

## Project Overview

- **Name:** MossMan (Core)
- **Goal:** A modular Minecraft mod for ticket tracking, designed as a platform for agile integrations.
- **Mod ID:** `mossman`
- **Primary Namespace:** `com.mossman`
- **Main Stack:** Java 21 (Fabric) with an API-first approach.

## Project Strategy

Focus is exclusively on providing a high-quality, native in-game experience for ticket tracking within Minecraft.


## How to use this documentation
Agents should refer to `architecture.md` before making structural changes and `standards.md` when writing new code. Check `knowledge/` if you encounter unexpected behavior.
